# Swipelate

Bôi đen văn bản ở bất kỳ ứng dụng nào, bản dịch hiện ngay tại chỗ. Windows 10/11 và macOS (chip Apple).

**Trang chủ, hướng dẫn và tải về: https://swipelate.com/**

| Hệ điều hành | Tải bản mới nhất |
|---|---|
| Windows 10/11 x64 | [Swipelate-Setup-x64.exe](https://github.com/thydynh03/swipelate/releases/latest/download/Swipelate-Setup-x64.exe) |
| macOS 11+ (chip Apple) | [Swipelate-macOS-AppleSilicon.dmg](https://github.com/thydynh03/swipelate/releases/latest/download/Swipelate-macOS-AppleSilicon.dmg) |

Mỗi bản phát hành có tệp `SHA256SUMS.txt` để kiểm tra bộ cài. Các bản trước nằm ở mục [Releases](https://github.com/thydynh03/swipelate/releases).

Repo này chỉ dùng để phát hành bộ cài, không chứa mã nguồn. Câu hỏi và báo lỗi: https://swipelate.com/contact.html
