Chính sách quyền riêng tư

Cập nhật ngày 14/10/2026. Áp dụng cho ứng dụng Swipelate trên Windows (bản tải từ GitHub và bản trên Microsoft Store), macOS, tiện ích YouTube và trang web này.

Tóm tắt: Swipelate không có tài khoản, không bán hay chia sẻ dữ liệu, không quảng cáo. Văn bản bạn cần dịch chỉ được gửi tới dịch vụ dịch mà bạn chọn. Thống kê ẩn danh có thể tắt.

Văn bản bạn dịch

  • Khi bạn bôi đen hoặc chọn vùng màn hình để dịch, văn bản đó được gửi tới engine dịch bạn chọn trong Cài đặt: Google Translate (mặc định), DeepL, Anthropic Claude, hoặc địa chỉ API tương thích OpenAI do bạn nhập. Mỗi dịch vụ xử lý văn bản theo chính sách riêng của họ.
  • Nếu bật "tự dùng dự phòng khi engine chính lỗi" (bật sẵn), văn bản có thể được dịch bằng engine offline trên máy, rồi bằng engine khác mà bạn đã nhập API key (DeepL, Claude hoặc API tương thích OpenAI).
  • Engine Offline dịch ngay trên máy, không gửi văn bản đi đâu.
  • Nhận dạng chữ trên màn hình (OCR) chạy trên máy bằng Windows OCR hoặc Apple Vision. Ảnh chụp vùng màn hình không được lưu hay gửi đi.
  • Khi bật tra nghĩa tiếng Anh, từ đang tra được gửi tới Free Dictionary API, và tới Oxford Dictionaries API nếu bạn nhập khoá của họ.
  • API key bạn nhập (DeepL, Anthropic, OpenAI, Oxford) chỉ lưu trên máy và chỉ gửi tới đúng dịch vụ đó.

Dữ liệu lưu trên máy

Cài đặt, lịch sử dịch, sổ từ vựng, mục clipboard đã ghim và model dịch offline được lưu trong thư mục dữ liệu của ứng dụng trên máy bạn. Chúng không được gửi lên máy chủ nào. Bạn có thể tắt lưu lịch sử hoặc xoá lịch sử trong Cài đặt. Bản Microsoft Store xoá dữ liệu khi gỡ. Với bản cài từ GitHub, gỡ ứng dụng không xoá thư mục dữ liệu: xoá thư mục com.quicktranslate.app trong %APPDATA% (Windows) hoặc ~/Library/Application Support (macOS).

Thống kê ẩn danh

Để đếm số người dùng, ứng dụng gửi mỗi ngày một lần: một mã ngẫu nhiên tạo khi cài, số phiên bản và tên hệ điều hành. Không gửi văn bản bạn dịch, tên, email hay thông tin nhận dạng nào khác. Để chống spam, máy chủ thống kê lưu một giá trị băm (SHA-256, rút gọn) của dải mạng gửi yêu cầu theo từng ngày, không lưu địa chỉ IP gốc. Tắt bằng mục "Gửi thống kê ẩn danh" trong Cài đặt.

Trang web này đếm lượt truy cập theo cách tương tự (một mã ngẫu nhiên lưu trong trình duyệt, tối đa một lần mỗi ngày) và không gửi gì khi trình duyệt bật Do Not Track. Phông chữ của trang tải từ Google Fonts, nên trình duyệt gửi địa chỉ IP và thông tin trình duyệt tới Google khi mở trang.

Kết nối mạng khác

  • Bản tải từ GitHub kiểm tra bản mới trên GitHub mỗi ngày (có thể tắt trong tab Giới thiệu). Bản Microsoft Store do Store cập nhật.
  • Model dịch offline được tải từ Hugging Face khi bạn bấm Tải về.

Thay đổi và liên hệ

Khi chính sách này thay đổi, ngày cập nhật ở đầu trang sẽ đổi theo. Câu hỏi về quyền riêng tư: mở issue tại github.com/thydynh03/swipelate/issues.

Summary in English

Swipelate has no accounts, ads or data sales. Text you translate is sent to the translation service you pick (Google Translate by default, DeepL, Anthropic Claude or an OpenAI-compatible API you enter); with fallback on (the default), a failed translation is retried offline, then with another engine you entered a key for. The Offline engine and OCR run on your device. Settings, history, vocabulary and API keys stay on your device. A daily anonymous ping (random install id, version, OS) counts users and can be turned off in Settings; for abuse protection the stats server keeps a truncated SHA-256 hash of the sender's network per day, never the IP address. The website loads fonts from Google Fonts. The GitHub build checks GitHub for updates; the Microsoft Store build is updated by the Store. Contact: GitHub issues.
